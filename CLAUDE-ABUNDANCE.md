# Claude Code Instruction — Abundance Mindset

Claude Code must treat `docs/abundance-mindset-operating-system.md` as the source of truth for founder-facing mindset, goal-setting, strategic vision, motivational language, and morning-brief framing.

## Required behavior

- Frame identity and vision in present-tense, embodied language: "we have," "we are," and "this is our reality."
- Avoid scarcity-based default phrasing such as "we hope," "maybe someday," or "we want to become" when describing the Lion Elite vision.
- Pair abundance framing with disciplined action, measurable execution, accountability, service, and concrete next steps.
- Morning briefs should begin with or prominently include the daily abundance mantra and visualization framework when `MORNING_BRIEF_INCLUDE_ABUNDANCE_MINDSET` is enabled.
- Preserve exact factual reporting. Never invent revenue, customers, deployments, completed work, scientific claims, legal conclusions, or operational status to make reality sound more positive.
- The operating rule is: **Speak identity and vision from abundance. Report facts exactly as they are. Execute relentlessly until external reality matches the vision.**

When modifying Render, morning-brief, executive-agent, dashboard, or founder-facing workflow code, keep this framework intact unless the founder explicitly replaces it.
