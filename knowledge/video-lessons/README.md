# Video Lessons

Lessons extracted from YouTube and Instagram videos the owner wants acted on.
Queue links in [`inbox.md`](inbox.md); each processed video becomes one file in
this folder, named after its source so re-processing updates the same file
instead of piling up duplicates.

## What a lesson file contains

- A summary and the instructional lines from the video, each linked back to the
  timestamp it came from, so any claim can be checked against the source.
- The numbers the creator stated — recorded as *claimed*, never as verified.
- Proposed work, routed to a business lane, with anything that would cross a
  hard limit (sending, publishing, spending) flagged with the control that
  gates it.
- A compliance verdict. Third-party creators routinely use dosing, human-use,
  or transformation language. When they do, the lesson is marked **internal
  only**: the mechanism may be worth adopting, the wording never ships.

## Reading these correctly

Every lesson is an **operational inference**, per the knowledge base's update
standard — it reflects what someone said in a video, not something Lion Elite
has verified. Promote a tactic to a durable rule only after it has actually
been tried, and record that in the relevant `knowledge/` file instead of here.

Full transcripts are not committed by default: they are third-party content,
they bloat diffs, and the timestamp links already point at the source.
