# Daily Command Center

Use this file every morning to decide what matters today.

## Daily Priorities

### Revenue
- What task today can create sales?
- What follow-up needs to happen?
- What offer needs to be pushed?

### Content
- What content needs to be posted?
- What content needs to be created?
- What message are we repeating this week?

### Operations
- What customer/order issue needs attention?
- What SOP needs to be created or improved?
- What process is currently messy?

### Growth
- What partnership, funding, real estate, or expansion task needs movement?

## Daily Checklist

- [ ] Review open GitHub Issues
- [ ] Pick top 3 tasks for the day
- [ ] Complete at least 1 revenue task
- [ ] Complete at least 1 content task
- [ ] Update any active documents
- [ ] Add new ideas as Issues
- [ ] Close completed Issues
