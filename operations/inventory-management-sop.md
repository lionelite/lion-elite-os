# Inventory Management SOP

Source basis: Google Drive `Inventory` sheet, which tracks product name, batch, dosage, amount, available for sale, sold, ordered, and tracking information.

## Purpose
Keep Lion Elite inventory accurate so sales, fulfillment, purchasing, and customer expectations stay organized.

## Inventory Fields
Each product should track:

- Product name
- Batch / cap color
- Dosage
- Amount on hand
- Available for sale
- Sold
- Ordered
- Tracking information
- Notes

## Daily Inventory Workflow

### 1. Check New Orders
Review new sales from:

- Website orders
- Rep sales
- Manual/in-person sales
- Client directory updates

### 2. Subtract Sold Products
For each paid order:

- Identify product
- Identify quantity
- Subtract from available for sale
- Move quantity into sold column if using sheet structure

### 3. Flag Low Stock
Mark any product that is low, fast-moving, or at risk of selling out.

Suggested low-stock rule:

- 0–5 units: critical
- 6–10 units: low
- 11–20 units: monitor
- 20+ units: healthy

### 4. Track Incoming Inventory
For any ordered product:

- Add expected quantity
- Add tracking number
- Add expected arrival date if available
- Do not count as available until received

### 5. Receiving Inventory
When products arrive:

- Confirm product count
- Confirm batch/cap/color
- Confirm dosage
- Inspect packaging
- Add to available inventory
- Save any supplier/order notes

## Weekly Inventory Review

- [ ] Reconcile sold products against order sheets
- [ ] Reconcile physical inventory against spreadsheet
- [ ] Review fast-moving products
- [ ] Build reorder list
- [ ] Identify dead stock
- [ ] Update purchasing plan

## Quality Control

- [ ] Inventory updated after every shipped order
- [ ] Incoming shipments logged
- [ ] Physical count checked weekly
- [ ] Low-stock items flagged
- [ ] Product names standardized

## Common Mistakes

- Counting ordered inventory as available before it arrives
- Forgetting in-person sales
- Different spellings for same product
- Not updating sold quantities after rep sales
- Not matching product dosage correctly

## Recommended Improvement
Create a master product naming system so every sheet uses the same exact product names.
