BuildPipeline

Security

BuildPipeline is designed so operational guardrails live below the prompt layer.

Access

Customer access uses expiring one-time links and opaque bearer sessions. Only token hashes are persisted for sessions and login links.

Workspace isolation

Workspace membership and roles scope access to customer data and actions. Agency client workspaces are isolated by workspace ID and membership.

Credentials

OAuth credentials are encrypted at rest using AES-256-GCM before database storage. Connector health is verified rather than inferred from the presence of credentials.

Outbound controls

Opt-outs, replies, suppression, sender health, credit limits, send windows and compliance checks can block delivery before a message leaves the runtime.

Webhooks

Outbound webhooks support HMAC signing and retries. Stripe webhook handling verifies signatures before provisioning customer access.
