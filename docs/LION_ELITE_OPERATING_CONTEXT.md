# Lion Elite Operating Context

This file is durable operating context for Claude Code, OpenAI agents, Render workers, and future engineering/marketing sessions. Read it before making Lion Elite marketing, content, outreach, customer-experience, website, or automation decisions.

## Execution style
- Build what can be built now. Do not waste time discussing hypothetical capabilities as if they were completed.
- Never claim an integration, deployment, upload, send, or automation is complete unless it actually is.
- Customer experience is a focal point: work backward from the customer's experience through acquisition, purchase, fulfillment, follow-up, retention, and referral.
- Improve systems continuously. Weak automation should be refined rather than allowed to keep producing low-quality output.

## Primary marketing objective: impulse conversion
For every website, landing page, post, Reel, ad, email, outreach message, offer, product presentation, and checkout flow, the primary commercial question is:

> Does this make the right prospect want to take the next valuable action now?

Optimize ethically for spontaneous action using immediate relevance, pattern interruption, anticipated reward, strong visual desire, obvious value, authentic proof, low cognitive load, minimal friction, one clear CTA, truthful urgency/scarcity, and fast mobile UX. Never use fabricated scarcity, fake testimonials, deceptive countdowns, or unsupported claims.

For B2B outreach, the impulse action is often reply, book, call, or request details rather than immediate checkout.

## Marketing Intelligence quality loop
Research -> Opportunity/Angle -> Hook -> Exact Brand/Product Asset -> Creative -> Product Accuracy QA -> Visual QA -> Copy QA -> Brand QA -> Compliance QA -> Audience Fit -> Impulse Conversion QA -> Platform QA -> Score -> Refine -> Recheck -> Publish -> Measure -> Learn.

Rules:
- Any mandatory checkpoint failure blocks publishing.
- Minimum publish score is 92/100 unless a stricter current rule exists.
- A high score never overrides a failed mandatory gate.
- Failed assets receive targeted revisions and loop through QA again.
- Scheduled time is never permission to publish weak or incorrect content.
- Measure downstream behavior: clicks, carts, purchases, replies, calls, revenue, retention.

## Lion Elite Wellness content rules
- Research/educational positioning.
- Do not provide dosing, human-use instructions, treatment guidance, or unsupported medical claims.
- Product-specific creative must use the exact approved Lion Elite Wellness vial for the compound and strength.
- Never invent a generic vial or substitute another compound.
- Never recreate or alter a label when the canonical asset is available.
- Use premium, realistic, science-forward, cinematic visuals rather than cheap/cartoonish AI graphics or textbook-style cards.
- Hooks should create curiosity: mechanism, pathway, receptor, research question, myth/fact, comparison, unexpected finding, or premium visual story.

Do not repeat the failure where a CJC-1295/Ipamorelin post displayed a Selank vial. Product-image mismatch is a hard Product Accuracy failure.

The static textbook-style `PEPTIDE INFO SERIES` format has underperformed stronger curiosity/mechanism/research-storytelling content and should not be the default creative format.

## Outreach agenda
Prioritize high-fit smaller businesses and self-employed operators nationally, especially personal trainers/coaches, independent gyms, boutique fitness businesses, wellness companies, compliant clinic partnerships, affiliates/creators, and transformation-focused service providers.

Pitch the business outcome relevant to the prospect. For trainers, emphasize client acquisition, stronger client experience, education/coaching infrastructure, differentiation, retention, and transformation support rather than generic product pitching.

## Website agenda
Design pages backward from the purchase decision:
Attention -> Recognition -> Desire -> Proof -> Value -> Objection removal -> Simple choice -> CTA -> Fast checkout -> Confirmation -> Follow-up.

Reduce friction, avoid unnecessary choice overload, surface authentic proof, make the primary CTA unmistakable, and use bundles/add-ons only when they improve the customer's decision.

## Continuous improvement
Marketing and customer-experience agents should use real performance data to weight future decisions. Winning hooks, visuals, CTAs, offers, audiences, and formats gain influence. Weak patterns lose influence. The objective is not continuous posting; it is continuous improvement in customer action and revenue quality.
