# Biomarker Testing Workflow

## Purpose
Create a repeatable process for offering biomarker testing to Lion Elite Beauty clients.

## Step-by-Step Client Journey

### 1. Client Enrolls
Client purchases or enters a Lion Elite Beauty program.

Collect:

- Name
- Email
- Phone
- Date of birth if required by platform
- Address
- Program selected
- Main goal
- Current concerns
- Current supplements/medications if relevant
- Preferred collection method

### 2. Select Biomarker Panel
Choose the panel based on the client's program and goal.

Examples:

- Fat loss: Weight Loss & Metabolism Panel
- Muscle/performance: Muscle & Performance Panel
- Longevity: Longevity Panel
- Hormone concerns: Hormone Optimization Panel
- General wellness: Foundation Wellness Panel

### 3. Submit Order Through Platform
Order is submitted through the lab testing platform.

Known workflow:

- Platform physician reviews/authorizes order.
- Approximate physician authorization fee: $5 per order.
- NPI is not required from Lion Elite Beauty if platform physician network is used.

### 4. Choose Collection Option
Client chooses one:

1. LabCorp draw center
2. BioBox at-home collection, when available and appropriate

### 5. Client Completes Collection
For LabCorp:

- Client receives lab order instructions.
- Client visits participating LabCorp draw center.
- Approximate LabCorp draw fee: $8.

For BioBox:

- Client receives at-home kit.
- Client follows kit instructions.
- Client returns sample as instructed by BioBox/platform.

### 6. Results Return
Results are received through the platform.

Track:

- Order date
- Collection method
- Collection completed date
- Results received date
- Review scheduled date
- Follow-up completed date

### 7. Results Review
Lion Elite Beauty reviews the results within coaching/wellness scope.

Focus on:

- Education
- Lifestyle context
- Program personalization
- Client awareness
- Follow-up recommendations

Do not diagnose, treat, or prescribe unless handled by a licensed provider.

### 8. Referral If Needed
If biomarkers appear clinically concerning, refer client to:

- Platform physician
- Personal primary care physician
- Appropriate licensed healthcare provider

### 9. Program Adjustment
Use findings to personalize:

- Nutrition strategy
- Training approach
- Recovery focus
- Supplement discussion where appropriate
- Retesting schedule
- Coaching accountability

### 10. Retesting
Suggested retest intervals:

- Foundation: every 6–12 months
- Weight loss/metabolism: every 8–12 weeks during active program
- Hormone-focused: every 8–16 weeks depending on provider guidance
- Longevity/VIP: quarterly or semiannually

## Client Status Options

- Intake Complete
- Panel Selected
- Order Submitted
- Awaiting Physician Authorization
- Awaiting Collection
- LabCorp Draw Scheduled
- BioBox Shipped
- Sample Collected
- Results Pending

- Retest Scheduled

- [ ] Collection method selected
- [ ] Physician fee noted

- [ ] Review completed
