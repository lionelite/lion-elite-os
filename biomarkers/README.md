# Lion Elite Beauty Biomarker Testing OS

This section manages the biomarker testing workflow for Lion Elite Beauty.

## Current Operating Model

Lion Elite Beauty does not need its own NPI to start if the lab platform provides access to its own physician network.

Known workflow details:

- Platform physician authorization fee: approximately $5 per order.
- LabCorp draw center collection fee: approximately $8 per draw/order.
- BioBox is the at-home collection option through the platform partner.
- Lion Elite Beauty should still operate within a coaching, wellness, and education scope.
- Medical diagnosis, treatment, prescriptions, and interpretation requiring a licensed provider should be handled by the platform physician or the client's own healthcare provider.

## Core Principle

The biomarker testing system should help personalize wellness programs, improve client experience, and create a premium service without positioning Lion Elite Beauty as diagnosing or treating disease unless a licensed medical provider is directly involved.
