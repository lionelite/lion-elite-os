# Environment Variable Template

Create a `.env` file on your deployment server. Do not commit the real `.env` file to GitHub.

Required variables:

- PORT
- PUBLIC_BASE_URL
- META_ACCESS_TOKEN
- META_AD_ACCOUNT_ID
- META_API_VERSION
- GA4_PROPERTY_ID
- GOOGLE_APPLICATION_CREDENTIALS_JSON
- GSC_SITE_URL
- ORCHID_API_BASE_URL
- ORCHID_API_KEY
- CRM_API_BASE_URL
- CRM_API_KEY
- GITHUB_TOKEN
- GITHUB_REPO

Example values should be stored only inside the deployment platform's secure environment settings.
